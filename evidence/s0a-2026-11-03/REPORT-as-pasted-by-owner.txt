### 3. Setup Report & Blockers

* **Total Setup Time:** ~25 minutes.
* **Blocker 1 (Docker Compose missing):** Docker CLI on host was missing the `compose` plugin. Installed `docker-compose-plugin v5.7.0` to `~/.docker/cli-plugins/docker-compose`.
* **Blocker 2 (WordPress version mismatch):** `docker-compose.yml` was pinned to `wordpress:6-php8.2-apache` (which ran WP 6.9.4). The latest WooCommerce (11.2.1) required WordPress 7.0+. Resolved by updating WordPress core to `7.1.4` via `wp core update`.
* **Blocker 3 (`smoke.test.mjs` URL encoding):** Space in directory path caused `new URL(...).pathname` to encode `%20`, throwing `MODULE_NOT_FOUND`. Fixed using `fileURLToPath` from `node:url`.
* **Blocker 4 (Checkout Shipping Validation):** Initial product was physical (`shipping_required: true`), but the fresh store had no shipping zones defined, causing PayPal's API to return `[UNPROCESSABLE_ENTITY] SHIPPING_ADDRESS_INVALID`. Resolved by setting the test product to `virtual: true`, which allowed `NO_SHIPPING` and checkout to succeed cleanly.
* **PayPal Connection Method:** Direct API authentication via the plugin's `authenticate_via_direct_api(true, client_id, secret)`. **No public URL was required** for connecting credentials in sandbox mode.
